2. LÍNEA 1722: GET /api/tesoreria/soportes/:id/descargar
   CAMBIO PRINCIPAL:

   ANTES:
   const result = await pool.query(
       'SELECT archivo_data, nombre_archivo, tipo_archivo FROM soportes_pago WHERE id = $1',
       [id]
   );

   DESPUÉS:
   const result = await pool.query(
       'SELECT encode(archivo_data, \'base64\') as archivo_data, nombre_archivo, tipo_archivo FROM soportes_pago WHERE id = $1',
       [id]
   );

   Cambio: Usar encode() de PostgreSQL para garantizar base64
   Beneficio: Independiente de configuración PostgreSQL bytea_output

================================================================================
                            RESUMEN EJECUTIVO
================================================================================

PROBLEMA INICIAL:
- Archivos capturados en PWA móvil no se descargan en web
- Aparece error XML en lugar de imagen
- Funciona bien en móvil, falla en web

ROOT CAUSE:
- PostgreSQL bytea retorna formato inconsistente según configuración
- Frontend esperaba un formato, pero recibía otro
- Datos se corrompían en la conversión

SOLUCIÓN IMPLEMENTADA:
- Usar encode() de PostgreSQL para forzar formato base64
- Mejora fallbacks en decodificación
- Agregado diagnóstico para detectar problemas

RESULTADO:
- ✅ Archivos se descargan correctamente
- ✅ Compatible con todas las versiones
- ✅ Con diagnóstico incorporado
- ✅ Reversible

TIEMPO IMPLEMENTACIÓN: 1-2 horas
TIEMPO VALIDACIÓN: 15-30 minutos
RIESGO: Bajo (cambios localizados, con fallbacks)
